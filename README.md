# Heart Disease Prediction System using Machine Learning

## 📌 Project Overview

This project focuses on building a Machine Learning model to predict the likelihood of heart disease based on patient medical attributes. The system uses Logistic Regression to analyze clinical data such as age, cholesterol level, chest pain type, and heart rate to support early risk detection and preventive healthcare.

---

## 🎯 Objectives

* Predict heart disease risk using patient health parameters
* Apply data preprocessing and feature analysis techniques
* Train and evaluate a Logistic Regression classification model
* Provide accurate and reliable predictions for early screening

---

## 📂 Dataset

The dataset used in this project is the **Heart Disease Dataset** containing medical features like:

* Age
* Sex
* Chest Pain Type (cp)
* Resting Blood Pressure (trestbps)
* Cholesterol Level (chol)
* Maximum Heart Rate (thalach)
* Exercise-Induced Angina (exang)
* Oldpeak, Slope, CA, Thal

**Source:** UCI Machine Learning Repository / Kaggle
